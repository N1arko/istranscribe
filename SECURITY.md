# Reporting a security issue

Use [GitHub's private vulnerability reporting](https://github.com/N1arko/istranscribe/security/advisories/new) for a vulnerability that could expose recordings, transcripts, provider keys, or local files.

Include the affected commit or version, the platform, reproduction steps, and the likely impact. Use synthetic data where possible. Ordinary bugs and feature requests belong in public issues.

The project is in early development. Security fixes are made on the current default branch; separate maintenance branches are not available yet.
