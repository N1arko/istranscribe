# WI-017: Опубликовать isTranscribe как open-source проект на GitHub

- Kind: `change`
- Canon action: `direct-edit`

## Outcome

Репозиторий `N1arko/istranscribe` доступен публично, исходный код имеет выбранную владельцем open-source лицензию, а README даёт внешнему читателю понятный вход в проект.

## Specs

- Governing: `spec://common/PROP-000#rules`
- Constraint: `spec://common/PROP-006-release-v2-product-canon#root`

## Scope

- In: аудит публикуемого Git-дерева и истории, лицензия исходного кода, публичный README, базовая информация для контрибьюторов, подготовка ветки и изменение видимости GitHub после решения владельца.
- Out: выпуск Microsoft Store, завершение транскрипционных WI, повторные тесты приложения и публикация пользовательских записей, настроек или моделей.

## Acceptance

- [x] Выбрана разрешительная MIT по запросу владельца о свободном использовании; корневой файл лицензии добавлен, условия сторонних компонентов сохранены.
- [x] README описывает назначение, текущие платформы и состояние функций, локальные данные, запуск сборки и навигацию по проекту.
- [x] Git-дерево и история просмотрены на секреты, пользовательские данные и материалы, требующие отдельного решения перед публикацией.
- [x] Подготовленные изменения опубликованы в GitHub по разрешению владельца; репозиторий виден без авторизации и GitHub распознаёт лицензию.

## Publication review

- Исходный приватный репозиторий содержит одну ветку; Releases, issues, pull requests и Actions runs отсутствуют. Владелец разрешил публикацию и выбрал сохранение прежней истории приватной.
- Публичная история начинается с чистого снимка исходников, документации и сохранённых Windows-исправлений. Автор публичных коммитов использует GitHub noreply-адрес. Прежняя история сохранена отдельно.
- В Git нет отслеживаемых баз данных, моделей, записей встреч, файлов ключей или сертификатов. Отслеживаемые аудиофикстуры `piecewise.*` содержат синтетические тоны для проверки декодирования.
- Поиск типовых секретов в дереве и истории нашёл только синтетические строки в тестах; сканирование имен файлов в истории не нашло приватных артефактов. Полная гарантия отсутствия произвольных секретов из этого поиска не следует.
- Текущие документы используют переносимые пути. Приватная история не входит в публичный снимок.
- README доступен на английском и русском; добавлены инструкции сборки, хранения данных, сторонних лицензий и участия, формы issues и приватный канал для security reports.

## Result

Опубликовано 2026-09-26: https://github.com/N1arko/istranscribe.

- GitHub показывает `Public` и распознаёт MIT. Публичная история начинается
  с `e69d555e24a2dd0b589c427d51e5d9446129b2bd`, без родительских коммитов.
- Прежняя история сохранена в отдельном приватном репозитории и локальных
  Git bundle. Публичные коммиты используют GitHub noreply-адрес.
- Добавлены English/Russian README с существующей иконкой приложения,
  инструкции сборки, privacy/third-party docs, CONTRIBUTING, SECURITY,
  формы bug/feature issues и PR template.
- Включены приватные сообщения об уязвимостях, поиск секретов и защита push.
- Проверены локальные ссылки документации, состав публикуемых файлов,
  отсутствие известных личных идентификаторов и оформление README
  в браузере без авторизации. Тесты приложения для этой публикации не запускались.
- Открытая публикация исходников сохраняет незавершённую приёмку WI-005,
  WI-006 и WI-016. Пользовательские записи, настройки и кэш моделей
  в репозиторий не входят.
