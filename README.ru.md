isTranscribe работает в трее и спрашивает, нужна ли запись, когда замечает начало встречи. После разговора аудиофайл появляется в выбранной папке. Запись можно запустить и вручную.

У транскрибации три режима: выключена, локальный Whisper или онлайн через собственный ключ Groq либо OpenRouter. Раздельные дорожки микрофона и системного звука помогают отличить ваш голос от голосов собеседников.

## Что уже есть

Это ранняя публикация исходников. В репозитории есть запись, транскрибация и инструменты сборки приложения. Ручная проверка распознавания встреч, настройки провайдеров и точности разделения голосов ещё продолжается. Подробности — на [доске задач](specs/BOARD.md).

| Платформа | Состояние |
| --- | --- |
| Windows x64 | Основная платформа разработки. Есть упаковка MSIX и локальная транскрибация на CPU/Vulkan. |
| macOS на Apple Silicon | Есть нативные компоненты и сборка app/DMG; приёмка платформы продолжается. |
| Linux, Windows ARM64, Intel Mac | Поддерживаемого способа сборки пока нет. |

Первый публичный релиз содержит исходный код. Подписанный установщик появится отдельным релизом после подготовки.

## Как это устроено для пользователя

- Запись начинается после подтверждения или ручного запуска. Кнопки управления доступны в небольшом плавающем окне.
- Аудио хранится в выбранной папке. При ошибке транскрибации запись остаётся доступной.
- Локальная транскрибация использует Whisper `large-v3-turbo`. Модели загружаются отдельно от установщика.
- Онлайн-транскрибация отправляет аудио выбранному провайдеру после согласия пользователя. Провайдер может брать плату за обработку.
- Интерфейс работает на русском и английском.

Аккаунт isTranscribe не нужен. В [описании хранения данных](docs/PRIVACY.md) перечислено, что остаётся на компьютере и когда приложение обращается к внешним сервисам.

## Запуск из исходников

Для Windows понадобятся Git и .NET 10 SDK версии из [global.json](global.json). Команды для PowerShell:

```powershell
git clone https://github.com/N1arko/istranscribe.git
cd istranscribe
dotnet run --project src/IsTranscribe.App.Windows/IsTranscribe.App.Windows.csproj -c Release -r win-x64
```

Команда запускает настольное приложение. Для локальной транскрибации нужны worker и нативные библиотеки, которые добавляет полная сборка пакета. Её шаги и сборка для macOS описаны в [инструкции](docs/BUILDING.md).

## Участие в проекте

В баг-репорте пригодятся версия ОС, последовательность действий и результат. Идеи и исправления тоже приветствуются. Начать можно с [инструкции для участников](CONTRIBUTING.md); об уязвимости можно [сообщить приватно](SECURITY.md).

Приложение написано на C# с .NET 10 и Avalonia. Общая логика находится в `src/IsTranscribe.Application` и `src/IsTranscribe.Core`, захват звука и интеграции с ОС — в платформенных модулях. Решения о поведении приложения собраны в [карте спецификаций](specs/SPEC-MAP.md).
