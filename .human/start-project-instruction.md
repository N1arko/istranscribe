# Как начать работу с проектом

Для текущего проекта используй [how-it-works.md](./how-it-works.md). Новая AI-сессия начинает с `AGENTS.md` и `specs/protocols/BOOT.md`.

Перед claim work item создай локальный `specs/.me` из `.me.template`; этот файл не коммитится.

Для новой отслеживаемой работы создай `specs/work/WI-NNN-short-slug.md`, добавь одну компактную строку в `BOARD.md` и создавай WAL checkpoint только при handoff или остановке незавершённой работы.
